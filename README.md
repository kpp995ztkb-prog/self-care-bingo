# Self-care Bingo · 自我关爱

一个适配手机和桌面的自我关爱九宫格，使用原生 HTML、CSS 和 JavaScript，无需安装依赖或构建。

## 本地运行

```sh
python3 -m http.server 5173 --directory dist
```

打开 http://localhost:5173/。手机预览时，让设备与电脑连接同一 Wi-Fi，并访问电脑的局域网 IP 和端口 5173。

## 功能

- 点击替换卡片、左右滑动选卡、长按拖动换位、随机换一组。
- 完成卡片后盖星星，只有新完成的卡片播放动画。
- 新增三格连线时，两侧播放礼花。
- 本地保存、链接分享、卡片图片下载。

## 项目结构

- `dist/index.html`：页面入口。
- `dist/style.css`：响应式样式与动效。
- `dist/app.js`：交互、状态、分享和图片导出。
- `dist/assets/`：插画及纹理素材。
- `.openai/hosting.json`：现有 Sites 发布配置。

## 验证

```sh
node --check dist/app.js
```

手动检查手机布局、拖拽和滑动、连续点亮与连线礼花、刷新恢复、分享及图片导出。浏览器开启减少动态效果时会缩减动画。

## 数据与素材

打卡记录保存在浏览器本地。分享链接包含卡片内容和完成状态，转发前请确认内容。插画素材来自用户提供的设计文件，未另行授予素材或项目的开源许可。
